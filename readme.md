# Browser Extensions

A dumping ground for random browser extensions and scripts I write for personal use. 
Most of these are just quick fixes for minor daily annoyances. 
They are unpolished and the list is constantly changing.

### How to use(If you're here you probably already know)
A few of the Firefox extensions are published on the Mozilla Add-ons store since it is free. 
For everything else, including all Chrome extensions, you will have to load them manually. 
Enable Developer Mode in your browser and load the specific extension folder as unpacked.
